# 深圳住区外围街道安全感知研究网页

本仓库用于展示《高密度城市既有住区外围街道安全感知影响因素研究——以深圳为例》的网页化研究成果。

## 部署方式

1. 新建 GitHub 仓库。
2. 将本文件夹中的 `index.html` 和 `README.md` 上传到仓库根目录。
3. 进入仓库 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. 保存后等待 1–3 分钟，即可获得 GitHub Pages 访问链接。

## 文件说明

- `index.html`：网页主体文件，包含页面样式、交互逻辑和嵌入图片资源。
- `README.md`：仓库说明文件。
